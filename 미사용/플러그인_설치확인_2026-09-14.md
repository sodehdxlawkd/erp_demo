## 3. 플러그인별 상세

### ① slack (v1.2.0)
채팅 Slack과 연동. 메시지 검색·전송·요약, Block Kit UI 제작, Slack 앱 개발까지.
- 명령어: `/slack:standup`, `/slack:channel-digest`, `/slack:summarize-channel`,
  `/slack:draft-announcement`, `/slack:find-discussions`
- 스킬: `slack-api`, `slack-cli`, `slack-docs`, `slack-messaging`, `slack-search`,
  `block-kit`, `create-slack-app`

### ② feature-dev
새 기능을 "코드베이스 파악 → 설계 → 리뷰" 순서로 만들어주는 도구.
- 명령어: `/feature-dev`
- 에이전트: `code-architect`(설계) · `code-explorer`(기존 코드 분석) · `code-reviewer`(검토)

### ③ frontend-design
화면 디자인(색·타이포·여백)을 템플릿 티 안 나게 잡아주는 가이드.
- 스킬: `/frontend-design`

### ④ find-skills
지금 열려 있는 프로젝트를 분석해서, 도움될 만한 스킬/플러그인을 추천.
- 스킬: `/find-skills`

### ⑤ superpowers (v6.3.0) — 이번에 새로 설치
작업 "방식"을 체계화하는 스킬 묶음 14개.

| 분류 | 스킬 |
|---|---|
| 기획 | `brainstorming`, `writing-plans` |
| 실행 | `executing-plans`, `subagent-driven-development`, `dispatching-parallel-agents` |
| 품질 | `test-driven-development`, `systematic-debugging`, `verification-before-completion` |
| 리뷰 | `requesting-code-review`, `receiving-code-review` |
| 작업환경 | `using-git-worktrees`, `finishing-a-development-branch` |
| 기타 | `writing-skills`, `using-superpowers` |

### ⑥ playwright (MCP 서버)
브라우저를 자동으로 열고 클릭·입력·스크린샷·콘솔로그 확인이 가능.
이 프로젝트에서는 **`index.html`을 실제로 열어 노선 필터를 클릭하고,
PRD의 성공기준 S1~S12 숫자가 화면에 맞게 나오는지 눈으로 검증**하는 데 쓸 수 있음.
