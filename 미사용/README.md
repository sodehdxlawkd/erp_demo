# 미사용 — 인사총무 실습 앱과 무관한 파일들

2026-09-15, 이 폴더의 작업을 **교육용 가상 인사총무 ERP 실습 앱 하나**로 좁히면서
관계없는 파일을 여기로 옮겼습니다. **앞으로 읽지도 고치지도 않습니다.**

| 파일 | 원래 무엇이었나 |
|---|---|
| `dart.html` | 금융감독원 전자공시(DART) 정기보고서 조회 화면 — 실제 기업 데이터, 성격이 전혀 다른 앱 |
| `gemini/gemini_호출.py` | Gemini API 호출 예제 (파이썬) |
| `.env` · `.env.example` | 위 두 개가 쓰던 API 키 (`DART_API_KEY`, `GEMINI_API_KEY`) |
| `플러그인_설치확인_2026-09-14.md` | 일회성 점검 기록 |
| `claude_냉동컨테이너대시보드_옛문서.md` | 예전 '냉동컨테이너 부킹 대시보드' 프로젝트의 CLAUDE.md. 이 폴더에 없는 파일들을 설명하고 있어 그대로 두면 계속 잘못된 안내를 합니다 |

함께 정리한 것:
- `index.html` — 'DART 조회 화면 열기' 카드 삭제
- `로컬서버.mjs` — DART 중계 코드와 `.env` 읽는 부분 삭제 (지금은 파일만 내려주는 순수 정적 서버)

되돌리려면 이 파일들을 상위 폴더로 옮기고, 위 두 파일의 삭제분을 git 이력에서 되살리면 됩니다.
